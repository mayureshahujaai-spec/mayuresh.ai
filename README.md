# Signal AI — AI News & Tools Guide

This is a static website for GitHub Pages.

## Upload these files
Upload `index.html`, `style.css`, and `script.js` to the **root** of your repository, all at the same level.

The HTML references `style.css` and `script.js` in the root. Do not put them in a `static` folder unless you update those paths.

## Publish
Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

This page is a curated resource hub, not an automatically updating news feed. Links point to provider pages; check the source before sharing news claims.
